# Domera

Property management and bookkeeping software for Swedish landlords and housing co-operatives (BRF).

We publish free MCP tools and SDKs so any assistant or system can work with Swedish building compliance.

- Website: https://domera.se
- LinkedIn: https://www.linkedin.com/company/domera-se/
- API docs: https://domera.se/api-dokumentation
- Free MCP server: [`mcp-server`](https://github.com/Domera-proptech/mcp-server) · endpoint `https://mcp.domera.se/mcp`
- Contact: hej@domera.se
